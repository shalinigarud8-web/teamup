# TeamUp Website

A responsive TeamUp landing/portfolio-style website built with plain HTML, CSS and JavaScript.

## Deploy to Vercel
1. Upload the `teamup-vercel` folder to a GitHub repository, then import it into Vercel.
2. Framework preset: Other.
3. Build command: leave empty.
4. Output directory: leave empty.
5. Deploy.

You can also drag the project folder into a Vercel deployment workflow that accepts a project upload.

The contact form is front-end only; connect a backend or form service if you want real email delivery.
